# Terminal, sessões e as três interfaces

`Conferido na documentação oficial para a versão 2.1.295 em 09/10/2026`

## Conceito · 10 min

**Modo terminal com `!`.** Começar o pedido com `!` roda o comando direto, sem passar pelo Claude. A saída entra no contexto e o Claude comenta o resultado (isso custa como um pedido normal). Bom para checagens rápidas: `! node --version`, `! git status`.

**Sessões.** Cada conversa é salva automaticamente e fica **ligada à pasta** onde foi aberta. Por isso, sempre abra o Claude Code dentro da pasta do projeto.

| Comando | O que faz |
|---|---|
| `claude -c` | Continua a conversa mais recente **desta pasta** |
| `claude -r` | Abre a lista de conversas para você escolher |
| `claude -n aula-05` | Abre uma conversa já com nome |
| `/rename nome` | Dá nome à conversa atual |
| `/resume nome` | Troca para outra conversa, de dentro do Claude Code |
| `/btw pergunta` | Pergunta rápida que **não entra** na conversa nem ocupa contexto |
| `/diff` | Mostra as mudanças feitas nos arquivos |
| `/export` | Salva a conversa como texto |

Para sair: `Ctrl+C` duas vezes com a caixa vazia, ou `Ctrl+D` duas vezes.

**As três interfaces** usam o mesmo agente, mas cada uma brilha numa situação:

| Interface | Melhor para |
|---|---|
| **Terminal** | Tudo aparece aqui primeiro. Comandos, automações e o dia a dia da trilha |
| **Desktop** | Trabalhar visualmente, com várias sessões em paralelo e prévias |
| **VS Code** | Ver o código e as mudanças lado a lado enquanto o Claude trabalha |

Cada interface guarda a sua própria lista de sessões. O Desktop consegue retomar uma sessão iniciada no terminal.

## Prática guiada · 40 min

**1. Modo terminal.** Rode:

```text
! node --version
```

e depois:

```text
! git --version
```

Leia o comentário que o Claude faz sobre cada saída.

**2. Dê nome à sessão.**

```text
/rename aula-s01a5
```

**3. Saia e continue.** Saia com `Ctrl+C` duas vezes. No PowerShell, rode `claude -c`. Pergunte "Qual foi o primeiro comando que rodamos nesta sessão?" para confirmar que é a mesma conversa.

**4. Use a lista de sessões.** Saia de novo e rode `claude -r`. Navegue pelas sessões da semana com as setas e use `Espaço` para ver uma prévia. Abra a `aula-s01a5`.

**5. Pergunta lateral.**

```text
/btw qual arquivo criamos na aula S01A1?
```

Repare que a resposta aparece numa caixa à parte e não entra na conversa.

**6. Veja as mudanças.** Rode `/diff` e olhe o que mudou na pasta durante a semana.

**7. Teste as outras interfaces.** Abra a pasta do laboratório no VS Code e faça o mesmo pedido pelo painel do Claude:

```text
Liste os arquivos que existem em exercicios/semana-01/.
```

Depois faça o mesmo no app Desktop, aba **Code**. Anote em `exercicios/semana-01/interfaces.md` quando você pretende usar cada uma.

> **No Desktop / No VS Code:** o `!` e os comandos de sessão são do terminal. No Desktop e no VS Code, as conversas antigas ficam numa lista lateral. Use essas interfaces com a pasta do laboratório aberta, para o Claude trabalhar no lugar certo.
