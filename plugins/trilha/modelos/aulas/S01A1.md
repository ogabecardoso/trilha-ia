# Como o Claude Code trabalha

`Conferido na documentação oficial para a versão 2.1.295 em 09/10/2026`

## Conceito · 10 min

O Claude Code não é um chat que só responde. Ele é um **agente**: recebe um pedido e **age no seu computador** até terminar. Para agir, ele usa ferramentas:

| Ferramenta | O que faz | Exemplo |
|---|---|---|
| Ler e buscar | Abre arquivos e procura texto ou nomes | Ler o `CLAUDE.md` antes de responder |
| Editar e escrever | Cria e altera arquivos | Criar uma página HTML |
| Terminal | Roda comandos | `node --version`, `git status` |
| Web | Pesquisa e lê páginas | Conferir a documentação de uma biblioteca |

Todo pedido passa por um ciclo que se repete até o trabalho ficar pronto:

**Você pede → Claude lê e reúne contexto → planeja → age (edita ou executa) → confere o resultado.** Se faltar algo, ele volta a ler e repete. Quando está pronto, responde a você.

Três ideias para guardar:

1. **Ele trabalha na pasta onde você abriu o Claude Code.** Essa pasta é o "projeto". Abrir na pasta errada é o erro mais comum de iniciante.
2. **Você continua no comando.** Pode interromper a qualquer momento com `Esc`, mandar uma correção enquanto ele trabalha (a mensagem entra numa fila) e decidir o que ele pode fazer sem perguntar (aula S01A4).
3. **Tudo o que ele lê ocupa espaço na memória da conversa**, o *contexto*. Isso tem custo, e a próxima aula trata disso.

Pense num técnico júnior muito rápido, com acesso remoto à sua máquina. Ele faz o trabalho, mas você define o que ele pode fazer sozinho e confere o resultado. O seu papel na trilha é aprender a **dirigir** esse técnico.

## Prática guiada · 40 min

**1. Abra o Claude Code na pasta certa.** No PowerShell:

```powershell
cd "{{PASTA_LAB}}"
claude
```

Repare na linha de baixo da tela: ela mostra o modo de permissão atual. Guarde o nome que aparece; ele volta na aula S01A4.

**2. Peça uma explicação sem mudanças.** Copie e envie:

```text
Explique o que existe nesta pasta e para que serve cada arquivo e subpasta. Não altere nada.
```

Enquanto ele trabalha, observe as linhas que mostram as ferramentas usadas (leitura de arquivos, buscas). Quando terminar, aperte `Ctrl+O` para ver os detalhes de cada passo. Aperte de novo para voltar.

**3. Peça uma criação.**

```text
Crie o arquivo exercicios/semana-01/ola.md com três frases sobre o que eu quero aprender nesta trilha: virar especialista em soluções com IA, saber vender e saber entregar.
```

Se ele pedir permissão, leia o que está sendo pedido antes de aceitar. Se não pedir, é porque o modo atual libera edições. Você vai controlar isso na aula S01A4.

**4. Interrompa no meio.**

```text
Liste 40 ideias de pequenos sistemas que eu poderia vender para negócios locais, com uma frase de explicação para cada.
```

Quando ele estiver no meio da lista, aperte `Esc`. Depois redirecione:

```text
Pare. Quero só 5 ideias, focadas em salões de beleza e estúdios de estética.
```

**5. Mande uma mensagem com ele trabalhando.** Faça um pedido qualquer e, enquanto ele trabalha, digite outra mensagem e aperte `Enter`. Ela fica na fila (em cinza) e é entregue assim que ele terminar a ação em andamento.

**6. Peça um relatório da sessão.**

```text
Resuma, passo a passo, o que você fez nesta sessão e quais ferramentas usou em cada passo.
```

> **No Desktop / No VS Code:** o agente é o mesmo, com as mesmas ferramentas. No app Desktop, abra a aba **Code** e escolha a pasta do laboratório. No VS Code, abra a pasta (**Arquivo > Abrir pasta**) e clique no ícone do Claude para abrir o painel. Nos dois, as edições aparecem como diferenças visuais lado a lado.
